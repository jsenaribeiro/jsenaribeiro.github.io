## Folder semantics

Special folders are exclusive and managed by framework.

<section class='infos'>

| | |
|-|-| 
| /apis | Scripts with exporteds function for RESTful requests |
| /builds | Rendered and transpiled content ready to deploy |
| /assets | Public static content, like imagem, sound, fonts, etc |
| /routes | Folder for component pages with directory routing |
| /controls | Standard control components handled by storybook |
| /directives | Injectable props similar to Angular attribute directive |

</section>
