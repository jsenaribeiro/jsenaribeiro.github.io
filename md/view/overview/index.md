# Reactful

**Reactful** is a modern React framework with comprehensive features and new concepts as stateful objects, props directives and function decorators.

<fieldset class='divs' style='margin-top:0px; display:block'>
<legend> innovations </legend>
<br/>

|                 Stateful object |               Props directive                | Function decorator                       |
| ------------------------------: | :------------------------------------------: | :--------------------------------------- |
| Self-rendering stateful objects | Angular-like injectable attribute directives | Built-time function decorator transpiler |

</fieldset>

<fieldset class='infos'>
<legend> features </legend>

|                        |                                           |
| ---------------------: | ----------------------------------------- |
|      easy data binding | two way data binding for React            |
|  flex hybrid rendering | SSR, ISR and SSG with function decorators |
|  lean stateful handing | hookless self-rendering stateful objects  |
| nice component routing | routing by props, path and decorators     |
|   bold props directive | angular-like injectable attributes        |
|      fast bundler tool | bun-based designed framework              |

</fieldset>
