## Startup files

<section class='infos'>

|              |                                                      |
| ------------ | ---------------------------------------------------- |
| .env         | Environment file integrated (.env.development, etc)  |
| .ignore      | Git ignored pre-filled with its common ignored files |
| index.ts     | Entry TypeScript file where the server is started    |
| index.html   | HTML wrapper and static dependencies in `<head>`     |
| sitemap.xml  | SEO sitemap created automatically by framework       |
| package.json | Configuration file with pre-configured scripts       |
| bun.lockb    | Bun automatic locked file                            |
| robot.txt    | Optional file used in SEO crawlers                   |
